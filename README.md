# Интерактивные учебники

Сайт-библиотека интерактивных учебников на React: выводы формул (KaTeX), живые визуализации,
ссылки на первоисточники и код, который можно запустить.

## Учебники

| Учебник | О чём |
|---|---|
| [GPT с нуля](books/gpt/README.md) | как устроены GPT и LLM: от производной до своей обученной модели, 20 глав |
| [Базы данных изнутри](books/db/README.md) | устройство СУБД (хранение, индексы, запросы, транзакции, восстановление, распределённость) и виды баз данных, 14 глав |

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # статическая сборка в dist/ (base: './' — открывается с любого пути, в т.ч. GitHub Pages)
```

Адреса: `#/` — библиотека, `#/<учебник>/<глава>` — глава (например, `#/gpt/attention`).

## Структура

```
src/                 платформа: библиотека, читалка, навигация, темы, прогресс
  books.js           реестр учебников
  shared/            общие компоненты: формулы, код, графики, виджеты, цитирование
books/
  README.md          как добавить новый учебник
  _template/         шаблон учебника
  gpt/               учебник «GPT с нуля» (главы, свой JS-код, библиография, python/)
  db/                учебник «Базы данных изнутри»
```

Чтобы добавить учебник — см. [books/README.md](books/README.md).
