# Как добавить учебник

Каждый учебник — отдельная папка `books/<id>/`. Платформа (`src/`) отвечает за библиотеку, оглавление,
навигацию, темы, отметки прогресса и библиографию; учебник — только за содержание.

## Шаги

1. Скопируйте шаблон: `cp -r books/_template books/<id>` (`<id>` — латиница, попадёт в адрес `#/<id>/<глава>`).
2. В `books/<id>/index.js` заполните `id`, `title`, `subtitle`, `description`, `icon`, `tags`, список `chapters`.
3. Напишите главы в `books/<id>/chapters/` — каждая глава это React-компонент.
4. Заполните библиографию `books/<id>/lib/refs.js` (только первоисточники с работающими ссылками).
5. Зарегистрируйте учебник в `src/books.js`:
   ```js
   import gpt from '../books/gpt/index.js';
   import myBook from '../books/<id>/index.js';
   export const BOOKS = [gpt, myBook];
   ```
6. `npm run dev` — учебник появится на главной странице.

## Структура учебника

```
books/<id>/
  index.js        — описание учебника и список глав
  chapters/       — главы (React-компоненты)
  lib/            — код и данные, нужные только этому учебнику (в т.ч. refs.js)
  python/ ...     — по желанию: запускаемый код для практики; листинги можно
                    вставлять в главы через import src from '../python/file.py?raw'
  README.md       — по желанию: как запускать практическую часть
```

## Формат главы в `index.js`

```js
{ id: 'attention', num: 10, part: 'Часть IV. Трансформер', title: 'Механизм внимания', component: Attention }
```

`part` группирует главы в оглавлении (можно не указывать), `num` — номер, который видит читатель.

## Общие компоненты (`@shared/...`)

| Импорт | Что это |
|---|---|
| `M`, `Eq`, `r` из `@shared/ui.jsx` | формулы KaTeX: `<M t={r\`x^2\`} />`, `<Eq t={...} label="..." />` |
| `Cite`, `Paper` | ссылка на статью из `refs.js` книги: `<Cite id="vaswani2017" />` |
| `Code` | блок кода с подсветкой (python, javascript, bash) и копированием |
| `Callout` | врезка: `note`, `tip`, `warn`, `history`, `danger`, `math` |
| `Quiz` | вопрос с вариантами ответа и объяснением |
| `Widget`, `Slider`, `Stat`, `Bars` | рамка интерактивного виджета и элементы управления |
| `LineChart`, `Heatmap`, `ContourCanvas` из `@shared/charts.jsx` | графики, тепловые карты, карты уровня |
| `makeRng`, `softmax` из `@shared/rng.js` | воспроизводимые случайные числа |

Цвета берите из CSS-переменных (`var(--c1)` … `var(--c6)`, `var(--accent)`) — тогда виджеты работают в светлой и тёмной теме.

Папка `_template` не зарегистрирована в `src/books.js` и на сайте не показывается.
