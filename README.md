# GPT с нуля — интерактивный учебник

Интерактивный учебник на React о том, как устроены GPT и большие языковые модели: от производной и
скалярного произведения до собственной обученной модели. Каждая формула выводится, каждая строка кода
объясняется, утверждения подкреплены ссылками на первоисточники (60+ статей, см. главу 19).

## Запуск учебника

```bash
npm install
npm run dev      # режим разработки
npm run build    # статическая сборка в dist/ (открывается с любого пути, base: './')
```

## Практическая часть (`python/`)

Весь код из учебника — рабочие файлы, проверенные запуском:

| Файл | Что делает | Глава |
|---|---|---|
| `micrograd.py` | скалярный autograd с нуля, проверка градиентов, обучение на XOR | 5 |
| `bigram.py` | биграммная модель подсчётом и нейросетью | 7 |
| `bpe.py` | байтовый BPE-токенизатор: обучение, encode/decode, сохранение | 8 |
| `model.py` | GPT (архитектура GPT-2) с нуля на PyTorch | 9–13 |
| `prepare.py` | текст → токены → `train.bin`/`val.bin` (символы или BPE) | 14 |
| `train.py` | AdamW, warmup+cosine, grad clipping, накопление градиента, bf16/fp16 | 14 |
| `sample.py` | генерация с temperature / top-k / top-p | 15 |

```bash
cd python
pip install -r requirements.txt
python prepare.py                       # Tiny Shakespeare, символьный токенизатор
python train.py --device cpu --n_layer 4 --n_head 4 --n_embd 128 --block_size 64 \
    --batch_size 32 --max_iters 1500 --eval_interval 500 --eval_iters 20 --dropout 0.0 --lr 2e-3
python sample.py --start "ROMEO:" --top_k 40
```

Последняя команда обучения занимает ~2.5 минуты на 4 ядрах CPU и даёт val loss ≈ 1.72
(стартовый ≈ ln 65 = 4.17, биграммная модель ≈ 2.45). С видеокартой запустите `python train.py`
с настройками по умолчанию (≈10.7M параметров). Подробности и таблица конфигураций — глава 17.
