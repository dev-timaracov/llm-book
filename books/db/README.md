# Базы данных изнутри

Учебник о том, как устроены СУБД и какими они бывают. 25 глав: от реляционной модели и SQL через
хранение, индексы, исполнение запросов и транзакции до распределённых и облачных систем, обзора видов
баз данных (колоночные, key-value, документные, графовые, векторные) и аналитики (OLAP, хранилища
данных, Data Lake, Spark, потоки). Около 50 интерактивных виджетов и 117 первоисточников.

## Практика (`python/`, только стандартная библиотека)

| Файл | Что делает | Глава |
|---|---|---|
| `normalize.py` | замыкание, ключи, минимальное покрытие, BCNF-декомпозиция, синтез 3NF | 2 |
| `colcompress.py` | RLE, словарь, упаковка бит, FOR, дельта; сравнение с zlib | 5 |
| `btree.py` | B+-дерево: поиск, вставка с делением, диапазоны, проверка инвариантов | 6 |
| `lsm.py` | LSM-хранилище: WAL + fsync, memtable, SSTable, Bloom-фильтр, компакция, восстановление | 7, 13 |
| `query.py` | исполнитель Volcano: scan, filter, project, 3 алгоритма соединения, sort, aggregate | 8, 10 |
| `extsort.py` | внешняя сортировка: прогоны, замещающий выбор, многопроходное слияние | 9 |
| `mvcc.py` | MVCC: снимки, потерянное обновление, write skew, serializable | 11, 12 |
| `vector_index.py` | точный kNN и IVF-индекс, recall@k | 20 |
| `mapreduce.py` | MapReduce на процессах: map, shuffle, reduce, комбайнер | 22 |

```bash
cd books/db/python
for f in normalize colcompress btree lsm query extsort mvcc vector_index mapreduce; do python $f.py; done
```
