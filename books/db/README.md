# Базы данных изнутри

Учебник о том, как устроены СУБД и какими они бывают. 14 глав: путь запроса от SQL до байтов на диске
и обратно, с симуляторами (страница со слотами, буферный пул, B+-дерево, LSM, Bloom-фильтр, порядок
соединений, аномалии изоляции, MVCC, восстановление ARIES, согласованное хеширование, кворумы) и
ссылками на первоисточники (~60 статей).

| Часть | Главы |
|---|---|
| Введение | 0. Карта пути |
| I. Хранение | 1. Диск, страницы и записи · 2. Буферный пул |
| II. Индексы | 3. B+-деревья и хеш-индексы · 4. LSM-деревья и Bloom-фильтры |
| III. Запросы | 5. Выполнение запросов · 6. Оптимизатор |
| IV. Транзакции | 7. Транзакции и изоляция · 8. Блокировки и MVCC · 9. Журнал и восстановление |
| V. Масштаб и виды | 10. Распределённые БД · 11. Виды баз данных · 12. Практикум · 13. Библиография |

## Практика (`python/`, только стандартная библиотека)

| Файл | Что делает | Глава |
|---|---|---|
| `btree.py` | B+-дерево: поиск, вставка с делением, диапазоны, проверка инвариантов | 3 |
| `lsm.py` | LSM-хранилище: WAL + fsync, memtable, SSTable, Bloom-фильтр, компакция, восстановление | 4, 9 |
| `query.py` | исполнитель Volcano: scan, filter, project, 3 алгоритма соединения, sort, aggregate | 5, 6 |
| `mvcc.py` | MVCC: снимки, потерянное обновление, write skew, serializable | 7, 8 |

```bash
cd books/db/python
python btree.py && python lsm.py && python query.py && python mvcc.py
```
